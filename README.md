[TAO Community Edition](https://github.com/tao-ce/tao-ce) is usually shipped as a container image.

This Appliance distribution will allow to deploy TAO Community Edition in a complete system, in various format:

* a System-on-Chip like Raspberry Pi
* a virtual machine
* a physical computer

## How-to

To install your own appliance, follow [Installation guide](https://tao-ce.github.io/tao-ce/start/install/) in our documentation.
